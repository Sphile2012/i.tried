## ⚡ Quick Reference

### Essential Commands
```bash
# Navigate to backend
cd artifacts/backend

# Install dependencies
npm install

# Setup database
npm run prisma:migrate

# SEED ALL 30 TOPICS ⭐⭐⭐
npm run prisma:seed:complete

# Start server
npm run start:dev

# View database
npm run prisma:studio
```

### Critical File
📄 **artifacts/backend/prisma/seed-complete-topics.ts**  
This file creates all 30 topics with 6,000+ code examples

### Command to Run It
```bash
npm run prisma:seed:complete
```
